# AutoComponent · Vitrina interactiva

Landing page interactiva (React + Tailwind CSS 4 + Lucide) del proyecto escolar **AutoComponent**.
Autores: David Leonardo Garces Vesga y Julian David Hernandez Quintero.

## Ejecutar en local
```bash
npm install
npm run dev
```

## Publicar en GitHub Pages
```bash
npm run deploy
```
Luego, en el repositorio: Settings → Pages → Branch `gh-pages` / carpeta `/ (root)`.

## Personalizar
Todo el contenido está en `src/AutoComponent.jsx`. Cambia el enlace `REPO_URL` y la lista `PARTS`
(componentes y número de cajón) por los datos reales del taller.
